プライバシーポリシー / Privacy Policy

最終更新日: 2026年11月8日

本ツールは YouTube API Services を使用しています。本ツールを使うことで、YouTube 利用規約に同意したものとみなされます。Google によるデータの扱いは Google プライバシーポリシーをご覧ください。

対象

本ポリシーは、YouTubeチャンネル「ただの会社員」の運営者が自分専用に使うツール「ただの会社員 自動投稿」(以下、本ツール)に適用されます。本ツールを利用できるのは運営者本人のみです。

取得する情報

本ツールは YouTube API Services を利用し、運営者がGoogleアカウントで許可した範囲で、運営者自身のYouTubeチャンネルの情報(動画の一覧・状態、アナリティクスの集計値)にアクセスします。運営者以外の個人情報は取得しません。

利用目的

動画のアップロード、サムネイルの設定、公開状況の確認、運営者自身のチャンネルの分析にのみ使います。

保存と共有

認証情報と取得したデータは運営者のコンピューター内にのみ保存し、第三者に提供・販売・共有しません。

データの削除

YouTube API Services から取得したデータは、利用目的に必要な期間だけ保存し、公開統計(再生数など)は30日以内に更新または削除します。運営者が許可を取り消した場合は、保存している認証情報と取得データを7日以内に削除します。

アクセスの取り消し

Googleアカウントのサードパーティのアクセス設定から、いつでも本ツールへの許可を取り消せます。

YouTube と Google のポリシー

本ツールは YouTube 利用規約 と Google プライバシーポリシー に従って YouTube API Services を利用します。

お問い合わせ

YouTubeチャンネル「ただの会社員」のコメント欄からご連絡ください。

English summary

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service; see the Google Privacy Policy. It accesses only the channel owner's own channel data (video list/status and analytics) with the owner's OAuth consent, stores it only on the owner's computer, and never shares or sells it. Public statistics are refreshed or deleted within 30 days, and all stored credentials and data are deleted within 7 days after access is revoked. Access can be revoked at any time at Google security settings.
