プライバシーポリシー

最終更新日: 2026年11月8日

対象

本ポリシーは、YouTubeチャンネル「ただの会社員」の運営者が自分専用に使うツール「ただの会社員 自動投稿」(以下、本ツール)に適用されます。本ツールを利用できるのは運営者本人のみです。

取得する情報

本ツールは YouTube API Services を利用し、運営者がGoogleアカウントで許可した範囲で、運営者自身のYouTubeチャンネルの情報(動画の一覧・状態、アナリティクスの集計値)にアクセスします。運営者以外の個人情報は取得しません。

利用目的

動画のアップロード、サムネイルの設定、公開状況の確認、運営者自身のチャンネルの分析にのみ使います。

保存と共有

認証情報と取得したデータは運営者のコンピューター内にのみ保存し、第三者に提供・販売・共有しません。

アクセスの取り消し

Googleアカウントのサードパーティのアクセス設定から、いつでも本ツールへの許可を取り消せます。

YouTube と Google のポリシー

本ツールは YouTube 利用規約 と Google プライバシーポリシー に従って YouTube API Services を利用します。

お問い合わせ

YouTubeチャンネル「ただの会社員」のコメント欄からご連絡ください。
